WasmBridge: RGBA memory + Canvas

WebAssembly and a matching JavaScript implementation invert RGB pixels inside a reusable, bounded RGBA8 buffer. Alpha is preserved. The program copies the result into a fresh Canvas ImageData.


Images larger than 512 x 512 are scaled down. Default sample is 256 x 160. The test also compares against a separate reference algorithm.
